# Maze Generator & Solver

Projet réalisé en Python dans le cadre de mon apprentissage en algorithmique, programmation orientée objet et stack.

## Fonctionnalités

- Génération procédurale de labyrinthes avec DFS
- Résolution avec BFS
- Résolution avec A*
- Affichage ASCII
- Visualisation graphique avec Pygame
- Affichage du chemin trouvé

## Concepts utilisés

- Programmation orientée objet
- Structures de données (pile, file, tas)
- Algorithmes de graphes
- Backtracking
- Pathfinding
